# Anotações de Git

Comandos praticados durante meu laboratório de Git e GitHub.

## Inicialização

### `git init`
Inicializa um novo repositório Git.

### `git status`
Mostra o estado atual dos arquivos do repositório.

## Staging e commits

### `git add`
Adiciona alterações à área de preparação (staging).

Exemplo:

```bash
git add README.md
