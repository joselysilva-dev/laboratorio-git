# 🧪 Laboratório Git

Laboratório prático criado para estudar **Git, GitHub e controle de versão** por meio da execução de comandos e registro do aprendizado.

O repositório funciona como um ambiente de prática para acompanhar minha evolução no uso do Git durante os estudos de Engenharia de Software.

---

## 📌 Sobre o laboratório

O objetivo deste repositório é praticar conceitos fundamentais de controle de versão utilizando Git.

Em vez de registrar apenas conteúdo teórico, o laboratório é utilizado para executar comandos, criar commits, acompanhar alterações e observar o histórico do repositório na prática.

---

## 🎯 Objetivos

Durante o laboratório, são praticados conceitos como:

- criação e inicialização de repositórios;
- acompanhamento do estado dos arquivos;
- preparação de alterações para commit;
- criação de commits;
- consulta do histórico;
- comparação entre versões;
- utilização de branches;
- integração entre Git e GitHub;
- documentação dos comandos utilizados.

## 📚 Conceitos praticados

### Repositório

Um repositório Git permite acompanhar as alterações realizadas nos arquivos de um projeto ao longo do tempo.

### Commit

Um commit registra um conjunto de alterações no histórico do repositório.

### Branch

Uma branch permite trabalhar em uma linha de desenvolvimento separada.

Neste laboratório, a branch principal é:

```text
main
```

### Histórico

O Git permite consultar os commits realizados e acompanhar a evolução do repositório.

### Diff

O `git diff` permite visualizar diferenças entre estados dos arquivos e alterações realizadas.
